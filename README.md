# Docker - A Practical Guide 🐳

Learn Docker the practical way - from your first container to shipping a real app
in production. A hands-on course in **Arabic and English** that keeps things short
and concrete: explain the idea, show it, then practice it in a lab.

Every concept is taught generally first, then applied to a real
**Spring Boot + PostgreSQL** app - so you see it working, not just described - and
it wraps up with a bank of real interview questions to test yourself.

---

## 📖 Read it live


- 🇸🇦 **Arabic (RTL):** https://ma7moud3ly.github.io/docker-practical-guide/
- 🇬🇧 **English (LTR):** https://ma7moud3ly.github.io/docker-practical-guide/en/

Every page has a **🌐 language toggle** in the header that jumps to the same
chapter in the other language.

---

## ✨ Features

- **Bilingual** - full Arabic and English editions that mirror each other.
- **10 chapters** per language, each with theory, diagrams, examples, a lab, common mistakes, best practices, and a cheat sheet.
- **Interview bank** - 60+ real Docker interview questions grouped by topic.
- **Dark mode by default**, with a light/dark toggle that persists.
- **Mermaid diagrams**, syntax-highlighted code with **copy buttons**, and a language indicator.
- **Responsive** with a collapsible sidebar, and **printable** to clean PDF.
- **No build step** - open `index.html` in a browser. Works on GitHub Pages.

## 🧩 Reuse this as a course template

Want to build your own course with this exact system? Everything is in the
[`guide/`](guide/) folder: read [`guide/GUIDE.md`](guide/GUIDE.md), then copy the
three scaffolds — `index.template.html`, `template.html`, and
`site-data.template.js` (fill the `{{PLACEHOLDER}}` tokens). The whole
`assets/` folder is a reusable engine; you only write your pages and the
`site-data.js` manifest. Topic-agnostic — any subject (or any LLM) can follow it.
